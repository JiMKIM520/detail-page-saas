# 누끼컷(배경 제거) 재검토

2026-08-06 · 근거: 2026-08-04 회의록, 2026-07-24 결정, 현재 코드

## 1. 결론부터

| 용도 | 필요한가 | 근거 |
|---|---|---|
| **AI 스타일링샷 입력용** | **불필요** | 회의: *"흰 배경으로 찍은 걸 주나 누끼를 주나 큰 차이가 없다"* (실측 비교는 아직 안 함) |
| **기업 납품용** | **필요** | 입점몰이 투명 썸네일을 요구하고, 소상공인이 직접 배경을 못 뗌 |

→ **AI 때문이 아니라 "기업 서비스"로서 줄 것인가**의 문제. 안 주기로 하면 개발 자체가 불필요하다.

## 2. 현재 상태

**받는 그릇은 이미 있고, 배경을 떼주는 기능만 없다.**

- `/photography` 업로드 → `studio_photo`로 저장 ✅
- 파이프라인이 `studio_photo`를 우선 사용 ✅
- **자동 배경제거 ❌ 미연결** (지금은 사람이 만들어 올리는 방식)

## 3. 선택지 (1,000장 기준)

| 방식 | 비용 | 연동 | 비고 |
|---|---|---|---|
| 수작업 유지 | 인건비 | — | 200개사엔 비현실적 |
| remove.bg | **$90~200** | 쉬움 | 7/24 회의에서 언급된 안 |
| 오픈소스 자체 실행 | $0 | **부담** | 워커가 Node라 파이썬·모델(100~200MB) 추가 필요. GPU 없어 장당 수 초 |
| **★ fal.ai BiRefNet v2** | **약 $1~2** | 쉬움 | REST 호출만. 구독·최소지출 없음 |
| fal.ai Bria RMBG 2.0 | $18 | 쉬움 | 상업 라이선스 명확 |

**오픈소스 주의** — 흔히 쓰는 `BRIA RMBG-1.4`는 **비상업 라이선스**라 용역 납품물에 부적합.
상업 가능한 건 `rembg`(U²-Net, Apache-2.0)·`BiRefNet`(MIT) 정도인데, 아껴지는 돈이 **$1~2**라 실익이 없다.

## 4. 권장안: fal.ai BiRefNet v2

- remove.bg 대비 **약 100배 저렴** ($0.0008/컴퓨트초)
- 서버에 아무것도 안 얹음 — 이미 Claude·Gemini API를 쓰는 것과 같은 패턴
- **덤**: fal.ai는 Kling·Seedance·Veo 등 **영상 모델도 같은 계정**으로 제공 →
  회의에서 미결인 **GIF 제작 도구**까지 한 창구로 묶을 수 있음

연동 위치: 업로드 직후 자동 처리 또는 관리자 **[배경 제거]** 버튼. 원본은 보존하고 누끼본을 별도 저장.
예상 작업량 **반나절**.

## 5. 결정해 주실 것

1. **누끼를 기업에게 제공할 것인가** (안 주면 개발 불필요)
2. **몇 컷을 줄 것인가** — 회의 미결(4컷? 6컷?). 여기서 비용이 정해짐
3. 도구 확정 — 샘플 3~5장이면 품질 비교 가능

> 참고: 회의에서 "돌려볼 수는 있죠"로 넘어간 **누끼 vs 흰 배경 스타일링샷 결과 비교**를
> 함께 해두면 1번 판단이 명확해진다.
